# 시선(詩線) — POETRY SPECTRUM

한국 근대시의 감정 사전과 문학적 해석을 함께 탐색하는 정적 웹 분석 앱입니다. 별도의 서버·API·패키지 설치 없이 HTML, CSS, JavaScript만으로 GitHub Pages에서 실행됩니다.

## 바로 보기

- **GitHub 저장소:** https://github.com/andrew89lee-alt/korean-poetry-emotion-map
- **웹앱 주소:** https://andrew89lee-alt.github.io/korean-poetry-emotion-map/

참고 예시 저장소를 보지 않고 독자적인 레이아웃과 분석 흐름으로 재구성했습니다.

## 사용 방법

1. 왼쪽 작품 목록에서 시를 선택하거나 제목·시인으로 검색합니다.
2. 감정 필터로 작품을 분류할 수 있습니다.
3. 원문의 감정 시어 위에 마우스를 올려 해당 정서를 확인합니다.
4. 감정 도넛·레이더·행별 흐름·유사 작품을 확인합니다.
5. `감성 비교`에서 전체 히트맵, PCA 지도, 감정 가중치를 조절합니다.
6. `내 시 분석`에 직접 시를 입력하면 외부 전송 없이 분석합니다.

## 감정 범주와 사전

| 범주 | 정의 | 사전 크기 |
|---|---|---:|
| 기쁨 | 행복, 즐거움, 생동감 | 20개 이상 |
| 슬픔 | 이별, 상실, 고통 | 20개 이상 |
| 희망 | 미래 기대와 의지 | 20개 이상 |
| 사랑 | 애정과 헌신 | 20개 이상 |
| 성찰 | 자아와 삶의 의미 돌아보기 | 20개 이상 |
| 저항 | 억압과 부조리에 맞서기 | 20개 이상 |
| 그리움 | 부재와 과거에 대한 갈망 | 20개 이상 |

사전은 `app.js`의 `EMOTIONS` 배열에 명시형 명사·형용사·동사 어휘로 구축했습니다.

## 분석 알고리즘

1. 입력 본문을 한글·영문 토큰 중심으로 정규화합니다.
2. 감정 사전의 각 어휘를 본문 전체에서 부분 문자열로 탐색합니다.
3. 범주별 시어 수를 가중치로 곱합니다.
4. 가중 합계의 비율을 계산하고 내림 후 잔여 비율을 잔여분이 큰 순서로 배분해 합계 100%를 유지합니다.
5. 검출 시어가 없으면 비율을 계산하지 않고 “검출 근거 부족”으로 표시합니다.
6. 작품 간 유사도는 감정 비율 벡터의 코사인 유사도로 계산합니다.
7. 감성 지도는 8차원 감정 벡터의 공분산 행렬에서 거듭제곱법으로 주성분 2개를 추정한 PCA 근사 지도입니다.

수치는 하드코딩하지 않고 모든 작품 선택·사용자 입력·가중치 조정 시 프로그램이 재계산합니다.

## 정량 분석과 문학 해석 불일치 검증 5개

1. **진달래꽃:** 수치가 슬픔을 높게 잡아도 문학적 해석은 이별을 상대의 안위를 위해 절제하는 배려로 읽습니다.
2. **그날이 오면:** 기쁨 시어보다 공동체 해방에 대한 저항과 희망이 해석상 더 중요하므로 수치와 주제어가 다르게 움직일 수 있습니다.
3. **거울:** 사전 어휘가 적어도 성찰과 분열된 자아는 반복되는 거울·왼손잡이 이미지로 해석합니다.
4. **십자가:** 고통과 죽음의 시어가 거대한 비중을 만들더라도 신앙적 희생과 의지라는 문학적 결단을 함께 해석합니다.
5. **빼앗긴 들에도 봄은 오는가:** 봄과 자연 시어는 기쁨·평온을 만들지만 남의 땅·빼앗김은 저항을 지배하는 맥락으로 읽습니다.

## 주요 기능

- 작품 목록, 제목·시인 검색, 감정 필터
- 원문과 감정 시어 색상 강조
- 감정 도넛 차트와 레이더 차트
- 행별 감정 변화 그래프
- 시어–감정–주제 연결 다이어그램
- 코사인 유사도 기반 유사 작품 3편 추천
- 전체 작품 감정 히트맵
- PCA 기반 감성 지도
- 감정 가중치 조절과 기본·조정 결과 비교
- 사용자 직접 입력 분석
- 감정 비율 기반 디지털 아트
- 다크·라이트 테마와 모바일 반응형 레이아웃

## 기술 스택과 파일 구조

- HTML5 / CSS3 / Vanilla JavaScript
- 외부 라이브러리 또는 유료 API 없음
- SVG와 Canvas 기반 시각화

```text
index.html   앱 구조와 탭
styles.css   다크·라이트 테마와 반응형 UI
data.js      15편 작품 데이터와 출처
app.js       감정 사전, 분석, 차트, PCA, 추천, 디지털 아트
.nojekyll    GitHub Pages 정적 자산 처리
README.md    프로젝트 설명과 출처
```

모든 참조 경로는 `./styles.css`, `./data.js`, `./app.js`처럼 상대 경로를 사용합니다.

## 한계와 개선 방향

- 형태소 분석기 없이 부분 문자열 사전을 사용하므로 문맥·반어·활용형 오탐이 발생할 수 있습니다.
- 작품의 실제 감정 빈도는 감정 확률이 아니라 사전 기반의 비교 지표입니다.
- PCA는 완전한 통계 구현이 아니라 시각화 목적의 거듭제곱법 근사입니다.
- 원문은 현대 표기 및 문헌 판본에 따라 띄어쓰기·어휘가 다를 수 있으므로 출처 확인이 필요합니다.
- 추후 한국어 형태소 분석과 문맥 임베딩을 위한 경량 데이터 전처리를 추가할 수 있습니다.

## GitHub Pages 배포

1. 저장소의 `Settings` → `Pages`로 이동합니다.
2. `Build and deployment`의 `Source`를 `Deploy from a branch`로 선택합니다.
3. 브랜치 `main`, 폴더 `/ (root)`를 선택해 저장합니다.
4. 배포가 완료되면 `https://andrew89lee-alt.github.io/korean-poetry-emotion-map/`에서 확인할 수 있습니다.

CLI로 설정할 경우:

```bash
gh api --method PUT repos/andrew89lee-alt/korean-poetry-emotion-map/pages \
  -f build_type=legacy \
  -f source='{"branch":"main","path":"/"}'
```
